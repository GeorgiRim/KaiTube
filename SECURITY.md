# Security and privacy

Do not post cookies, session files, tokens, private keys or account credentials in public issues. Cookie import is local; the app uses those credentials to contact YouTube. SD session storage is plaintext. Treat access to the SD as access to the session. Logs can contain viewing/search information; review and redact them before sharing.

For a suspected credential exposure, remove the affected files from shared locations and invalidate the relevant Google session. Report ordinary crashes with sanitized logs and reproduction steps.

No claim of a comprehensive security audit or guaranteed compatibility is made.
