# External SDK prerequisite

Place your own lawfully obtained `ounce-sdk.tar.xz` here. The SDK archive is deliberately not redistributed in this repository. Build scripts validate its SHA-256 against build-sdk.json and SDK.sha256. Required release: 20261113 (libounce db3f88a3, ouncevk 791c34e, ouncehen 9451c44). This repository cannot build without this prerequisite. No public download URL is asserted.
